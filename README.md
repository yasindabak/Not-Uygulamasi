# 📝 Not Uygulaması

Basit, hızlı ve kullanıcı dostu bir not alma uygulaması. Notlarınızı tarayıcınızda kaydedin, düzenleyin ve yönetin.

## ✨ Özellikler

- ✅ **Not Ekleme**: Başlık ve içerik ile kolayca not ekleyin
- 📝 **Metin Biçimlendirme**: 
  - **Kalın** (Bold)
  - *İtalik* (Italic)
  - <u>Altı Çizili</u> (Underline)
  - ~~Üzeri Çizili~~ (Strikethrough)
- ✏️ **Düzenleme**: Mevcut notları kolayca düzenleyin
- 🗑️ **Silme**: Artık ihtiyacınız olmayan notları silin
- 💾 **Otomatik Kaydetme**: Tüm notlarınız `localStorage` kullanarak tarayıcıda kaydedilir
- 🎨 **Kullanıcı Dostu Arayüz**: Minimalist ve temiz tasarım

## 🚀 Kullanım

1. **Sayfayı Açın**: `index.html` dosyasını tarayıcınızda açın
2. **Not Yazın**: 
   - "Not Başlığı" alanına başlık girin
   - "İçerik" alanına not içeriğini yazın
3. **Biçimlendirme**: İsteğe bağlı olarak biçimlendirme butonlarını kullanın
4. **Ekleyin**: "Ekle" butonuna tıklayın
5. **Yönetin**: Notlarınızı düzenleyin ✏️ veya silin 🗑️

## 📁 Dosya Yapısı

```
Not-Uygulamasi/
├── Not Uygulaması/
│   ├── index.html      # Ana HTML dosyası
│   ├── script.js       # JavaScript fonksiyonları
│   └── style.css       # SCSS stilleri
└── README.md           # Bu dosya
```

## 🛠️ Teknolojiler

- **HTML5**: Sayfanın yapısı
- **CSS/SCSS**: Stil ve tasarım
- **JavaScript**: Dinamik işlevsellik
- **LocalStorage API**: Veri saklama

## 💡 Nasıl Çalışır

- Eklediğiniz notlar `localStorage` kullanarak tarayıcınızda kaydedilir
- Sayfa yenilendiğinde daha önceki notlarınız otomatik olarak yüklenir
- Her not, başlık, içerik ve eylem butonları (düzenleme/silme) içerir

## 🎯 Başlamak

Uygulamayı kullanmak için:

```bash
# Repository'yi klonlayın
git clone https://github.com/yasindabak/Not-Uygulamasi.git

# Dosyasına gidin
cd Not-Uygulamasi

# index.html dosyasını tarayıcında açın
```
